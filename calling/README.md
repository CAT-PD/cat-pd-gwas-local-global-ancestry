### Repository structure

```bash=
root/
├── LICENSE

```

### Details
You can run IDAT calling pipeline with either `NeuroBooster_IDAT_Calling.ipynb` and build parallel batches from scratch. OR use `GenomeStudio_Caller.ipynb` developed by Dan Vitale to run IDAT calling in parallel. 

To learn more check this repository: https://github.com/dvitale199/genomestudio
